## Como exportar os JSONs

1. Abra o workflow no n8n
2. Menu `...` → **Download**
3. Salve aqui como `WF-DPV-NN.json` (ex: `WF-DPV-01.json`)
4. Commite: `git add workflows/ && git commit -m "wf: exportar WF-DPV-NN"`

> ⚠️ Exporte sempre que fizer alterações nos workflows.
